# 🎓 SkillCart - MERN Course Selling Platform

A full-stack course selling platform built as a learning project to explore modern web development using the MERN stack. The application enables users to browse and purchase courses securely, while providing administrators with tools to manage course content through a dedicated dashboard.

## 🚀 Live Demo

🔗 https://e-commerce-1-bx20.onrender.com

---

## ✨ Features

### 👤 User Features
- User Registration & Login (JWT Authentication)
- Browse available courses
- Search courses
- Purchase courses using Razorpay
- Access purchased course videos
- Responsive user interface

### 🛠️ Admin Features
- Secure Admin Authentication
- Create, Update & Delete Courses
- Upload course thumbnails using Cloudinary
- Manage course content from Admin Dashboard

---

## 🛠 Tech Stack

### Frontend
- React.js
- Redux Toolkit
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- JWT Authentication
- REST APIs

### Database
- MongoDB
- Mongoose

### Other Tools
- Razorpay
- Cloudinary

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/iamrahul-07/E-Commerce.git
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend folder and configure:

```env
MONGO_URL=
JWT_SECRET=
RAZORPAY_KEY_ID=
RAZORPAY_SECRET=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```
